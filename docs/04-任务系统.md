# 任务系统详解

本文档详细介绍六大任务的执行流程和核心逻辑。

## 1. 种田任务 (FarmingTask)

### 1.1 任务标识
```python
LABEL = "1. 种田 (智能版)"
```

### 1.2 参数配置

| 参数名 | 类型 | 说明 |
|-------|------|------|
| area_adb | text | 定位到田地附近 |
| field_select_adb | text | 点击田地弹出作物栏 |
| farm_info_pos | string | 农田说明图标坐标（用于复位） |
| close_seed_bar_adb | text | 无需播种时关闭作物栏 |
| crop_prompt_names | text | 作物名称提示（AI识别辅助） |
| sickle_pos | string | 镰刀位置坐标 |
| field_path | text | 田地划过轨迹坐标串 |
| crop_limits | string | 作物库存上限列表 |
| crop_pos_list | string | 作物种子位置列表 |
| crop_is_right_side | string | 作物是否在右侧页 |
| crop_bar_swipe_adb | text | 作物栏翻页动作 |
| stitch_left_x | int | 拼图左图保留宽度 |
| stitch_right_x | int | 拼图右图起始位置 |

### 1.3 执行流程

```
开始
  ↓
1. 点击田地 (field_select_adb)
  ↓
2. 截图判断状态
  ↓
3. AI识别：harvest / plant / wait
  ↓
4. 分支处理
  ├─ harvest → do_harvest() → do_plant_logic()
  ├─ plant → do_plant_logic()
  └─ wait → 无需操作
  ↓
结束
```

### 1.4 核心逻辑

#### 状态识别
```python
screenshot_path = "farm_state.png"
adb_screenshot(screenshot_path)

check_prompt = """
请分析这张游戏截图，判断当前处于什么状态。
只返回一个关键词：
- "harvest" : 画面底部有镰刀图标。
- "plant" : 画面底部有作物种子选择栏。
- "wait" : 其他情况。
"""

state = query_vlm(screenshot_path, check_prompt)
```

#### 收获逻辑
```python
def do_harvest(self):
    sickle = self.params.get("sickle_pos", "795 770")
    path = self.params.get("field_path", "")
    
    # 拼装drag_path命令
    full_cmd = f"drag_path {sickle} {path}\nsleep 1"
    
    execute_multiline_adb(full_cmd)
```

**原理**：
- 从镰刀位置开始
- 沿着预设路径连续拖拽
- 覆盖所有田地格子

#### 播种逻辑

**步骤1: 截图识别库存**
```python
# 左图
img_left = "crop_bar_1.png"
adb_screenshot(img_left)

# 翻页
execute_multiline_adb(self.params.get("crop_bar_swipe_adb"))
time.sleep(self.s_delay)

# 右图
img_right = "crop_bar_2.png"
adb_screenshot(img_right)

# 拼图
img_stitched = "crop_bar_full.png"
stitch_images(img_left, img_right, img_stitched, split_l, split_r)
```

**步骤2: AI识别库存**
```python
crop_names_str = self.params.get("crop_prompt_names", "")
count_prompt = f"请读取底部作物栏的库存数字，依次是[{crop_names_str}]，返回纯数字列表: [x, x, ...]"

ai_res = query_vlm(img_stitched, count_prompt)

# 正则提取数字
nums = re.findall(r'\d+', ai_res)
current_counts = [int(n) for n in nums]
```

**步骤3: 决策播种**
```python
limits = self.parse_list("crop_limits")
seed_pos_list = self.parse_list("crop_pos_list")
is_right_list = self.parse_list("crop_is_right_side")

# 找最缺的作物
target_index = -1
min_count = 99999

for i in range(len(current_counts)):
    curr = current_counts[i]
    limit = limits[i]
    if curr < limit and curr < min_count:
        min_count = curr
        target_index = i

if target_index != -1:
    # 判断需要翻页吗
    target_is_right = is_right_list[target_index]
    if target_is_right == 0:
        # 目标在左页，需要复位
        adb_click(*info_coords)
        execute_multiline_adb(field_select_adb)
    
    # 拼装播种指令
    seed_pos = seed_pos_list[target_index]
    path = self.params.get("field_path", "")
    plant_cmd = f"drag_path {seed_pos} {path}\nsleep 1"
    
    execute_multiline_adb(plant_cmd)
else:
    # 库存充足，关闭作物栏
    execute_multiline_adb(self.params.get("close_seed_bar_adb"))
```

### 1.5 关键技术

1. **AI状态识别**: 区分收获/播种/等待三种状态
2. **拼图识别**: 处理作物栏翻页，拼接完整库存图
3. **连续拖拽**: 使用Monkey脚本实现丝滑收割/播种
4. **智能决策**: 选择库存最低的作物进行补种

### 2.3 执行流程

```
开始
  ↓

    ├─ 处理单个地点
    │    ├─ 截图识别状态
    │    ├─ 分支处理
    │    │    ├─ 收获 → do_harvest() → do_production_logic()

    │    │    └─ 工作中 → 跳过
    │    └─ 完成
    └─ 切换地点 (nav_adb)
  ↓
```

### 2.4 核心逻辑

#### 状态识别
```python
screenshot_path = "gather_state.png"
adb_screenshot(screenshot_path)

check_prompt = "判断右下角按钮，从以下选择三选一：'收获'、'开始生产' 或 '加速' (工作中)。只回关键词。"
state = query_vlm(screenshot_path, check_prompt)
```

#### 生产逻辑

**步骤1: 轮询库存**
```python
current_counts = []
names = ['木材', '青竹', ...]
selects = ['input tap 1040 206', 'input tap 1160 206', ...]

for k in range(len(names)):
    # 1. 选中物品
    execute_multiline_adb(selects[k])
    time.sleep(self.s_delay)
    
    # 2. 截图（裁剪）
    img_name = f"item_{k}.png"
    crop_box = (1060, 394, 1160, 464)
    adb_screenshot(img_name, crop_box=crop_box)
    
    # 3. AI识别
    prompt = f"这是'{names[k]}'的库存数字特写。请识别图中的纯数字整数。"
    ai_res = query_vlm(img_name, prompt)
    
    # 4. 清洗数据
    ai_res = ai_res.replace('o', '0').replace('O', '0')
    nums = re.findall(r'\d+', ai_res)
    count = int(nums[0]) if nums else 9999
    
    current_counts.append(count)
```

**步骤2: 决策生产**
```python
target_index = -1
min_count = 99999

for i in range(len(current_counts)):
    curr = current_counts[i]
    limit = limits[i]
    if curr < limit and curr < min_count:
        min_count = curr
        target_index = i

if target_index != -1:
    # 再次选中
    execute_multiline_adb(selects[target_index])
    time.sleep(self.s_delay)
    
    # 点击生产
    btn_cmd = self.params.get("btn_pos")
    execute_multiline_adb(btn_cmd)
```

### 2.5 关键技术

1. **循环遍历**: 支持多个地点依次处理
2. **裁剪截图**: 只截取数字区域，提升识别准确率
3. **自动格子映射**: 根据物品数量自动取用前N个格子
4. **字符清洗**: 将AI误识别的'o'/'O'替换为'0'

### 3.3 执行流程

```
开始
  ↓

    ├─ 切换工坊 (nav_adb)
    ├─ 获取当前工坊数据
    │    ├─ ui_type: 0 或 1
    │    ├─ names: 产品名称列表
    │    └─ limits: 库存上限列表
    ├─ 分发逻辑
    │    ├─ Type 0 → process_normal_factory()
    │    └─ Type 1 → process_special_factory()
    └─ 完成
  ↓
结束
```

### 3.4 普通工坊逻辑

#### 流程
```
1. 收获（盲点6个生产位）
  ↓
2. 读取库存
  ├─ 点击右上角格子
  ├─ 截图识别
  └─ 记录库存
  ↓
3. 生产循环（填满6个坑位）
  └─ for slot in range(6):
        ├─ 找最缺的产品
        ├─ 点击选中
        ├─ 点击制作
        └─ 模拟库存+1
```

#### 贪心算法
```python
produce_btn = self.params.get("normal_produce_btn")

for slot_idx in range(6):  # 6个生产坑位
    target_idx = -1
    min_val = 99999
    
    # 找最缺的
    for k in range(len(current_counts)):
        curr = current_counts[k]
        limit = limits[k]
        
        if curr < limit and curr < min_val:
            min_val = curr
            target_idx = k
    
    if target_idx != -1:
        # 选中
        execute_multiline_adb(slot_adbs[target_idx])
        time.sleep(self.s_delay)
        
        # 制作
        execute_multiline_adb(produce_btn)
        time.sleep(self.s_delay)
        
        # 模拟库存+1（影响下次决策）
        current_counts[target_idx] += 1
    else:
        break  # 都不缺，退出循环
```

### 3.5 特殊工坊逻辑 (鸡舍/羊圈)

#### 流程
```
1. 收获（捡蛋/收蜜）
  ↓
2. 截图识别右下角资源
  ├─ AI读取：鸡蛋 20 鸡肉 0
  └─ 返回 [20, 0]
  ↓
3. 判断是否需要喂食
  └─ 如果任意资源 < 上限，则喂食
```

#### 识别逻辑
```python
img_name = "special_factory.png"
adb_screenshot(img_name)

prompt = f"请读取图片右下角'拥有：'后面的({names}物品的)数字列表。例如'拥有：鸡蛋 20 鸡肉 0'，请返回 [20, 0]。"
res = query_vlm(img_name, prompt)

# 提取数字
nums = re.findall(r'\d+', res)
current_owned = [int(n) for n in nums]

# 判断
should_feed = False
for k in range(len(current_owned)):
    if current_owned[k] < limits[k]:
        should_feed = True
        break

if should_feed:
    execute_multiline_adb(self.params.get("special_feed_btn"))
```

### 3.6 关键技术

1. **双UI适配**: 区分普通工坊和特殊工坊
2. **贪心算法**: 优先制作最缺的产品，一次性填满生产位
3. **模拟库存**: 制作后手动+1，影响后续决策
4. **大规模循环**: 支持27个工坊依次处理

## 4. 做菜任务 (CookingTask)

### 4.1 任务标识
```python
LABEL = "4. 做菜(固定位置/盲盒模式)"
```

### 4.2 参数配置

| 参数名 | 类型 | 说明 |
|-------|------|------|
| area_adb | text | 进入厨房 |
| cook_btn_adb | text | 开始/快速烹饪按钮ADB |
| quit_adb | text | 退出界面ADB |
| cook_batch_count | int | 单次制作次数 |
| position_adbs_list | text | 位置遍历列表ADB |
| dish_reset_adbs_list | text | 位置复位列表ADB |

### 4.3 执行流程

```
开始
  ↓
for i in range(len(position_adbs_list)):
    ├─ 1. 选中位置 (position_adbs[i])
    ├─ 2. 盲做 N 次 (cook_btn_adb * cook_batch_count)
    └─ 3. 复位/关闭弹窗 (dish_reset_adbs[i])
  ↓
结束
```

### 4.4 核心逻辑

#### 位置遍历
```python
pos_adbs = self.parse_list("position_adbs_list")
reset_adbs = self.parse_list("dish_reset_adbs_list")
cook_btn = self.params.get("cook_btn_adb")
batch_count = int(self.params.get("cook_batch_count", 1))

for i in range(len(pos_adbs)):
    curr_pos_cmd = pos_adbs[i]
    curr_reset_cmd = reset_adbs[i]
    
    # 1. 选中位置
    execute_multiline_adb(curr_pos_cmd)
    time.sleep(self.s_delay)
    
    # 2. 盲做
    for k in range(batch_count):
        execute_multiline_adb(cook_btn)
        time.sleep(self.s_delay)
    
    # 3. 复位
    execute_multiline_adb(curr_reset_cmd)
    time.sleep(self.s_delay)
```

### 4.5 关键技术

1. **盲点模式**: 不识别，直接按固定位置点击
2. **位置-复位配对**: 每个位置都有对应的复位动作
3. **批量制作**: 每个菜品可连续做N次

| 参数名 | 类型 | 说明 |
|-------|------|------|

### 5.3 执行流程

```
开始
  ↓

  ↓
```

### 5.4 核心逻辑

```python
slots = self.parse_list("slot_select_adbs")
deliver_cmd = self.params.get("deliver_btn_adb")

for i, slot_cmd in enumerate(slots):
    # 选中订单
    execute_multiline_adb(slot_cmd)
    time.sleep(self.s_delay)
    
    # 尝试交付
    # 如果满足条件，就交付；不满足，点了也没反应
    execute_multiline_adb(deliver_cmd)
    time.sleep(self.s_delay)
```

### 5.5 关键技术

1. **栏位循环**: 依次点击所有订单栏位
2. **盲点交付**: 不判断是否满足条件，直接点击
3. **容错设计**: 点击无效不会报错

## 总结

### 任务分类

#### 智能型任务
- **种田**: AI识别状态、拼图识别库存、智能决策
- **采集**: AI识别状态、裁剪截图、决策算法
- **加工**: 双UI适配、贪心算法、批量操作

#### 盲点型任务
- **做菜**: 固定位置遍历、批量制作
- **订单**: 栏位循环、盲点交付
- **蒲公英**: 固定流程、容错设计

### 关键技术总结

| 技术 | 应用任务 | 说明 |
|-----|---------|------|
| AI状态识别 | 种田、采集 | 判断当前界面状态 |
| 拼图识别 | 种田 | 处理翻页UI |
| 裁剪截图 | 采集、加工 | 提升识别准确率 |
| 连续拖拽 | 种田 | Monkey脚本实现丝滑划动 |
| 贪心算法 | 加工 | 优先制作最缺的产品 |
| 循环遍历 | 采集、加工、做菜、订单 | 批量处理 |
| 双UI适配 | 加工 | 普通工坊 vs 特殊工坊 |
| 盲点模式 | 做菜、订单、蒲公英 | 固定位置点击 |
