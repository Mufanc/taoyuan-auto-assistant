## 核心概念

### 分层架构
```
表现层 (ui.py)
    ↓
业务逻辑层 (logic.py)
    ↓
任务执行层 (tasks.py)
    ↓
工具层 (adb_utils.py + ai_client.py)
```

### 六大任务
1. 智能种田 - AI识别 + 连续拖拽
2. 多点采集 - 循环遍历 + 决策算法
3. 流水线加工 - 双UI适配 + 贪心算法
4. 批量烹饪 - 位置遍历 + 盲点模式
5. 自动订单 - 栏位循环 + 智能交付
6. 蒲公英闭环 - 固定流程 + 容错设计

### 关键技术
- **模板方法模式**: 统一任务执行流程
- **注册表模式**: 动态任务类型管理
- **配置驱动**: 所有参数可视化配置
- **Monkey脚本**: 实现连续拖拽
- **裁剪截图**: 提升AI识别准确率
- **贪心算法**: 优化生产决策
