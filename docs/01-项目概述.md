# 桃源自动助手 - 项目概述

## 项目简介

桃源自动助手是一个基于Python开发的游戏自动化工具，通过ADB（Android Debug Bridge）与模拟器通信，结合智谱AI的GLM-4V视觉大模型进行图像识别，实现游戏内各种任务的自动化执行。

## 核心特性

### 1. 技术架构
- **语言版本**: Python 3.10+
- **GUI框架**: Tkinter
- **图像处理**: Pillow
- **AI识别**: 智谱AI GLM-4V视觉大模型
- **设备控制**: ADB (Android Debug Bridge)
- **HTTP客户端**: httpx
- **数据验证**: pydantic

### 2. 六大核心功能

| 功能模块 | 说明 | 关键技术 |
|---------|------|---------|
| 智能种田 | 自动收获、判断库存、智能补种 | AI状态识别、拼图识别、连续拖拽 |
| 多点采集 | 巡逻伐木林、矿场等场景 | 循环遍历、库存识别、决策算法 |
| 流水线加工 | 工坊自动生产 | 双UI适配、贪心算法、批量操作 |
| 批量烹饪 | 连点制作缺货菜品 | 位置遍历、盲点模式 |
| 自动订单 | 一键交付订单 | 栏位循环、智能交付 |
| 蒲公英闭环 | 收获-装填-出发 | 固定流程、异常容错 |

### 3. 核心优势
- **视觉驱动**: 基于AI图像识别，无需修改游戏文件
- **灵活配置**: 所有坐标和参数可视化配置
- **循环执行**: 支持多轮自动化执行
- **多设备支持**: 自动检测和连接ADB设备
- **容错设计**: 状态复位机制保证流程稳定

## 项目结构

```
taoyuan-auto-assistant/
├── main.py                 # 程序入口
├── src/                    # 源代码目录
│   ├── ui.py              # GUI界面层
│   ├── logic.py           # 业务逻辑层
│   ├── tasks.py           # 任务执行层（6大任务）
│   ├── adb_utils.py       # ADB工具层
```

## 运行环境要求

### 硬件要求
- **模拟器**: 推荐MuMu模拟器
- **分辨率**: 1600x900 (DPI 240)
- **帧率**: 30FPS以上，不降帧

### 软件要求
- Python 3.10或更高版本
- ADB工具（通常包含在模拟器中）
- 智谱AI API Key

### 游戏设置
- 开启开发者选项中的"指针位置显示"（用于获取坐标）
- 相机高度设为"超远景"
- 确保UI元素不被遮挡

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 配置参数
1. 运行程序: `python main.py`
2. 进入"配置填写"页面
3. 填写API Key和ADB路径
4. 点击"保存并应用配置"

### 3. 创建任务
1. 进入"任务列表"页面
2. 点击"新建任务"
3. 选择任务类型
4. 配置任务参数
5. 勾选"启用"
6. 点击"全部启动"

## 配置文件说明

### data.json
程序运行时自动生成和更新，包含：
- **config**: 全局配置（API Key、延迟、坐标等）
- **tasks**: 任务列表（类型、参数、启用状态）

### 最终参数.json
提供默认配置参考，包含完整的任务配置示例。

## 注意事项

1. **首次使用前必须配置API Key**，否则无法进行AI识别
2. **ADB路径配置**：通常为 `模拟器安装目录/adb.exe`
3. **坐标获取**：通过模拟器开发者选项中的"指针位置"获取
4. **执行顺序**：任务按列表顺序依次执行
5. **状态复位**：每个任务执行前会先进行状态复位，确保起点一致
